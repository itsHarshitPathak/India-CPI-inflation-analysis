# India-CPI-inflation-analysis
## Project Overview
This project analyzes India's Consumer Price Index (CPI) data to identify inflation trends, category-wise price movements, and key economic patterns over time. The analysis focuses on understanding how major sectors such as food, fuel, housing, and transportation contribute to overall inflation in India.

Using Microsoft Excel, the dataset was cleaned, transformed, and analyzed through pivot tables, charts, and interactive visualizations to derive meaningful insights from monthly and yearly CPI changes. The project also examines inflation volatility and highlights the impact of external economic factors such as COVID-19 and crude oil price fluctuations on consumer prices.The final dashboard provides a clear and data-driven view of inflation behavior, helping users understand important trends and patterns within the Indian economy.
